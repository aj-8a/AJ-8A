## `01 / WHOAMI`

Hey! I'm **Aajimin (AJ-8A)** — a developer and project creator who enjoys turning ideas into real, usable digital experiences. I like building things from the ground up, experimenting with interfaces, solving bugs, and learning how systems work.

I’m drawn to the creative side of software and the analytical side of debugging: design a clear experience, understand what happens behind the scenes, test the details, and keep improving it.

- **Builder:** web apps, community experiences, learning projects, browser tools, and mini-games.
- **Developer mindset:** break big problems into smaller steps; test assumptions; improve through iteration.
- **Current interests:** frontend engineering, JavaScript, Python, responsive UI, APIs, and cloud-based app backends.
- **Cyber-inspired curiosity:** terminal workflows, system thinking, debugging, and learning security fundamentals responsibly.
- **Personal rule:** build real projects, document what I learn, and let the work keep getting better.

> `Curiosity is the spark. Consistency is the engine. Shipping is the proof.`
