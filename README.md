## `01 / WHOAMI`

Hey! I'm **Aajimin (AJ-8A)** — a developer, creator, and explorer who likes turning ideas into practical experiences people can use and enjoy.

I build things with a mix of curiosity and discipline: design the idea, shape the flow, test what matters, and keep polishing until it feels right. My work ranges from browser tools and learning apps to mini-games and creative web experiments.

- **Builder:** web apps, tools, community-first experiences, and mini-games.
- **Developer mindset:** break big problems into small steps; iterate quickly; improve what matters.
- **Current interests:** frontend engineering, JavaScript, Python, responsive UI, APIs, and cloud-powered project workflows.
- **Creative edge:** UI polish, game loops, user feedback, and making digital experiences feel alive.
- **Personal rule:** build real things, ship them, and keep learning from every release.

> `RO = Build. Play. Learn. Repeat.`
